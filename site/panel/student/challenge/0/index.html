کدی که همه این حالت‌ها را پوشش دهد، به‌عنوان راه‌حل قابل قبول ثبت می‌شود.

نمونه راه‌حل

def discount(price, percent):
    if price < 0:
        raise ValueError("price must be positive")
    return price * (1 - percent / 100)

print(discount(200, 15))
